This is for setting up the Google Chrome provider for people to test it out.

You can run it locally using DDEV. To do that, you need to have DDEV installed on your machine. You can find the installation instructions for DDEV here: https://ddev.readthedocs.io/en/stable/#installation.

Just do `ddev start` in the project directory, and it will set up the environment for you. Once it's up and running, you can access the Drupal site at `http://drupal-11-with-chrome-provider.ddev.site`.
